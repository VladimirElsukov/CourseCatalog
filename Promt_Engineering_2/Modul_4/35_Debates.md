# Метод «Дебаты»: организация спора между двумя позициями

В предыдущей статье вы узнали, как использовать метод «Экспертный совет» для получения мнений нескольких экспертов. Но даже если вы получили мнения нескольких экспертов, **они могут быть слишком «дружелюбными»** и не выявлять противоречия. В этой статье вы научитесь использовать **метод «Дебаты»** — технику, которая позволяет **организовать спор между двумя позициями** для глубокого анализа темы и выявления сильных и слабых сторон каждого аргумента.

## Суть метода «Дебаты»: противопоставление двух точек зрения для глубокого анализа темы

**Метод «Дебаты»** — это техника, при которой вы **задаёте две противоположные позиции** и просите их **спорить** между собой, приводя аргументы и контраргументы. Это позволяет **глубоко проанализировать тему** и выявить сильные и слабые стороны каждой позиции.

**Суть метода:**

- **Тезис** — чётко сформулированная позиция для обсуждения.
- **Сторона А** — позиция «за» тезис.
- **Сторона Б** — позиция «против» тезиса.
- **Аргументы** — обоснования каждой позиции.
- **Синтез** — обобщение выводов.

**Пример без «Дебатов»:**

```
Удалённая работа повышает продуктивность сотрудников.
```

**Результат:** Один общий ответ, который может быть односторонним.

**Пример с «Дебатами»:**

```
Провести дебаты по спорной теме «Удалённая работа повышает продуктивность сотрудников».

Сторона А («за»): Приводи 3 аргумента с примерами.

Сторона Б («против»): Приводи 3 аргумента с примерами.

В конце — обобщающие выводы (2–3 пункта).
```

**Результат:** Две противоположные позиции + обобщающие выводы.

## Структура дебатов: тезис → аргументы «за» → аргументы «против» → выводы

**Структура дебатов:**

1. **Тезис** — чётко сформулированная позиция.
2. **Аргументы «за»** — 3–5 аргументов с примерами.
3. **Аргументы «против»** — 3–5 аргументов с примерами.
4. **Выводы** — обобщение (2–3 пункта).

**Пример структуры:**

```
Тезис: «Удалённая работа повышает продуктивность сотрудников.»

Сторона А («за»):
1. Аргумент 1: «Сотрудники экономят время на дорогу.» Пример: «Вместо 2 часов в день на дорогу можно работать.»
2. Аргумент 2: «Меньше отвлекающих факторов.» Пример: «В офисе коллеги постоянно отвлекают, дома — тишина.»
3. Аргумент 3: «Гибкий график.» Пример: «Можно работать в удобное время, когда продуктивность выше.»

Сторона Б («против»):
1. Аргумент 1: «Отсутствие личного общения.» Пример: «В офисе можно быстро обсудить идею с коллегой.»
2. Аргумент 2: «Сложнее контролировать работу.» Пример: «Руководитель не видит, чем занимается сотрудник.»
3. Аргумент 3: «Размытие границ между работой и личной жизнью.» Пример: «Сотрудник работает допоздна, не может отключиться.»

Выводы:
1. Удалённая работа имеет как преимущества, так и недостатки.
2. Эффективность зависит от типа работы и личных качеств сотрудника.
3. Оптимально — гибридный формат (2–3 дня в офисе, остальное — удалённо).
```

## Как задать позиции сторон: чёткое определение тезиса, распределение ролей

**1. Чёткое определение тезиса**

**Формулировка:** «Тезис: „[однозначная позиция]“.»

**Пример:**

```
Тезис: «Удалённая работа повышает продуктивность сотрудников.»
```

**2. Распределение ролей**

**Формулировка:** «Сторона А („за“): Приводи аргументы в поддержку тезиса.»

**Пример:**

```
Сторона А («за»): Приводи 3 аргумента с примерами в поддержку тезиса.
```

**Формулировка:** «Сторона Б („против“): Приводи аргументы против тезиса.»

**Пример:**

```
Сторона Б («против»): Приводи 3 аргумента с примерами против тезиса.
```

**3. Правила ведения спора**

**Формулировка:** «Правила: 1) … 2) … 3) …»

**Пример:**

```
Правила:
1. Время на аргумент: 2–3 предложения.
2. Запрет на переход на личности.
3. Требование фактов и примеров.
```

## Управление аргументацией: правила ведения спора, критерии убедительности

**1. Правила ведения спора**

**Формулировка:** «Правила: 1) Время на аргумент: 2–3 предложения. 2) Запрет на переход на личности. 3) Требование фактов и примеров.»

**Пример:**

```
Правила:
1. Время на аргумент: 2–3 предложения.
2. Запрет на переход на личности.
3. Требование фактов и примеров.
```

**2. Критерии убедительности**

**Формулировка:** «Критерии убедительности: 1) Логика. 2) Примеры. 3) Статистика.»

**Пример:**

```
Критерии убедительности:
1. Логика: аргумент должен быть логически обоснованным.
2. Примеры: аргумент должен подкрепляться конкретными примерами.
3. Статистика: аргумент должен опираться на данные.
```

## Ограничения метода: риск субъективности, сложность управления эмоциональным накалом

**Ограничение 1: Риск субъективности**

Когда дебаты ведутся **без чётких критериев**, результат может быть **субъективным**.

**Решение:** Укажите **критерии убедительности** (логика, примеры, статистика).

**Ограничение 2: Сложность управления эмоциональным накалом**

Когда дебаты становятся **эмоциональными**, стороны могут **переходить на личности**.

**Решение:** Установите **правила** (запрет на переход на личности, время на аргумент).

**Ограничение 3: Поверхностность аргументов**

Когда стороны не подготовлены, их аргументы могут быть **поверхностными**.

**Решение:** Укажите **требование фактов и примеров**.

## Практические рекомендации по организации продуктивных дебатов

**Рекомендация 1: Чётко сформулируй тезис (однозначная позиция для обсуждения)**

**Некорректно:** «Обсуди тему удалённой работы.»

**Корректно:** «Тезис: „Удалённая работа повышает продуктивность сотрудников.“»

**Рекомендация 2: Распредели роли (кто „за“, кто „против“)**

**Некорректно:** «Обсуди тему удалённой работы.»

**Корректно:** «Сторона А („за“): Приводи аргументы в поддержку тезиса. Сторона Б („против“): Приводи аргументы против тезиса.»

**Рекомендация 3: Установи правила: время на аргумент, запрет на переход на личности, требование фактов**

**Некорректно:** «Обсуди тему удалённой работы.»

**Корректно:** «Правила: 1) Время на аргумент: 2–3 предложения. 2) Запрет на переход на личности. 3) Требование фактов и примеров.»

**Рекомендация 4: Определи критерии убедительности (логика, примеры, статистика)**

**Некорректно:** «Обсуди тему удалённой работы.»

**Корректно:** «Критерии убедительности: 1) Логика. 2) Примеры. 3) Статистика.»

**Рекомендация 5: Добавь этап синтеза: выявление общих точек, компромиссные решения**

**Некорректно:** «Обсуди тему удалённой работы.»

**Корректно:** «В конце — обобщающие выводы (2–3 пункта).»

**Рекомендация 6: Ограничь количество аргументов (3–5 на сторону оптимально)**

**Некорректно:** 10 аргументов на сторону.

**Корректно:** 3–5 аргументов на сторону.

**Рекомендация 7: Заверши выводами: что нового узнали, какие решения возможны**

**Некорректно:** «Обсуди тему удалённой работы.»

**Корректно:** «В конце — обобщающие выводы (2–3 пункта).»

Главное — чётко формулировать тезис, распределять роли, устанавливать правила и критерии убедительности, а также добавлять этап синтеза. В следующей статье вы узнаете, как комбинировать техники для создания сложных промптов.
