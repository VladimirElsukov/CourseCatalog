# Метод ReAct: рассуждение и действие поочерёдно

В предыдущей статье вы узнали, как использовать Tree-of-Thoughts для исследования нескольких вариантов решения. Но даже если вы рассмотрели несколько вариантов, **нейросеть всё равно работает в одном режиме** — либо рассуждает, либо действует. В этой статье вы научитесь использовать **ReAct** — метод, который позволяет нейросети **чередовать рассуждение и действие**, как это делают люди при решении сложных задач.

## Суть метода ReAct: чередование рассуждения («почему?») и действия («что сделать?»)

**ReAct** (Reason + Act) — это метод, который позволяет LLM **чередовать рассуждение и действие** в одном промпте. Вместо того чтобы генерировать весь ответ сразу, нейросеть:

1. **Рассуждает** («Почему это важно?»).
2. **Действует** («Что сделать?»).
3. **Наблюдает** за результатом.
4. **Повторяет** цикл.

**Суть метода:**

- **Рассуждение** — это анализ ситуации, объяснение, почему нужно сделать то или иное действие.
- **Действие** — это конкретный шаг, который нужно выполнить.
- **Наблюдение** — это результат действия.
- **Цикл** — повторение рассуждения и действия до достижения цели.

**Пример без ReAct:**

```
Найди и исправь ошибки в тексте статьи о климате.
```

**Результат:** Нейросеть может сразу выдать исправленный текст, но без объяснения, какие ошибки были и почему они были исправлены.

**Пример с ReAct:**

```
Найди и исправь ошибки в тексте статьи о климате. Работай по шагам:

Шаг 1: Проанализируй текст на логические ошибки. Объясни, почему ты считаешь это ошибкой.

Шаг 2: Проверь факты. Если факт неверен, исправь его и объясни, почему.

Шаг 3: Улучши стиль. Объясни, какие изменения ты вносишь и почему.

Шаг 4: Выведи финальную версию с комментариями к каждому исправлению.
```

**Результат:** Нейросеть выполняет задачу поэтапно, объясняя каждое действие и его обоснование.

## Структура промпта ReAct: план → шаг 1 (рассуждение + действие) → шаг 2 (рассуждение + действие) → вывод

**Структура ReAct-промпта:**

1. **План** — общее описание задачи и подхода.
2. **Шаг 1** — рассуждение («Почему это важно?») + действие («Что сделать?»).
3. **Шаг 2** — рассуждение + действие (повторение цикла).
4. **Вывод** — итоговый результат + краткое резюме рассуждений.

**Пример структуры:**

```
План: Найди и исправь ошибки в тексте статьи о климате. Работай по шагам.

Шаг 1: Проанализируй текст на логические ошибки. Объясни, почему ты считаешь это ошибкой. Если нашёл ошибку, исправь её.

Шаг 2: Проверь факты. Если факт неверен, исправь его и объясни, почему.

Шаг 3: Улучши стиль. Объясни, какие изменения ты вносишь и почему.

Шаг 4: Выведи финальную версию с комментариями к каждому исправлению.

Вывод: Итоговый текст + краткое резюме рассуждений.
```

## Когда применять: сложные задачи, требующие пошагового решения

**1. Сложные задачи**

Когда задача требует **много шагов** и **промежуточных решений**.

**Пример:**

- Анализ текста на ошибки.
- Решение математических задач.
- Диагностика проблем.

**2. Задачи, требующие объяснения**

Когда важно **объяснить**, почему было принято то или иное решение.

**Пример:**

- Медицинская диагностика.
- Юридический анализ.
- Финансовые решения.

**3. Задачи с неопределённостью**

Когда нужно **постепенно уточнять** информацию и принимать решения на основе промежуточных результатов.

**Пример:**

- Диалог с клиентом.
- Исследование проблемы.
- Планирование проекта.

## Примеры ReAct для разных сценариев (анализ данных, решение проблем, обучение)

**Пример 1: Анализ текста (полный рабочий промпт)**

```
Найди и исправь ошибки в тексте статьи о климате. Работай по шагам:

Шаг 1: Проанализируй текст на логические ошибки. Объясни, почему ты считаешь это ошибкой. Если нашёл ошибку, исправь её.

Шаг 2: Проверь факты. Если факт неверен, исправь его и объясни, почему.

Шаг 3: Улучши стиль. Объясни, какие изменения ты вносишь и почему.

Шаг 4: Выведи финальную версию с комментариями к каждому исправлению.

Вывод: Итоговый текст + краткое резюме рассуждений.
```

**Разбор:**

- **Шаг 1:** Рассуждение («Объясни, почему ты считаешь это ошибкой») + действие («Если нашёл ошибку, исправь её»).
- **Шаг 2:** Рассуждение («Объясни, почему») + действие («Исправь его»).
- **Шаг 3:** Рассуждение («Объясни, какие изменения») + действие («Улучши стиль»).
- **Шаг 4:** Действие («Выведи финальную версию») + рассуждение («с комментариями»).
- **Вывод:** Итоговый результат + резюме рассуждений.

**Пример 2: Решение проблем (полный рабочий промпт)**

```
Реши проблему: «Клиент жалуется на задержку доставки». Работай по шагам:

Шаг 1: Проанализируй ситуацию. Объясни, почему клиент мог остаться недовольным.

Шаг 2: Предложи решение. Объясни, почему это решение поможет.

Шаг 3: Составь ответ клиенту. Объясни, почему ты выбрал именно такую формулировку.

Шаг 4: Выведи финальный ответ с комментариями.

Вывод: Итоговый ответ + краткое резюме рассуждений.
```

**Разбор:**

- **Шаг 1:** Рассуждение («Объясни, почему») + действие («Проанализируй ситуацию»).
- **Шаг 2:** Рассуждение («Объясни, почему») + действие («Предложи решение»).
- **Шаг 3:** Рассуждение («Объясни, почему») + действие («Составь ответ»).
- **Шаг 4:** Действие («Выведи финальный ответ») + рассуждение («с комментариями»).
- **Вывод:** Итоговый результат + резюме рассуждений.

## Типичные ошибки: избыточные рассуждения, отсутствие чёткой последовательности

**Ошибка 1: Избыточные рассуждения**

**Некорректно:**

```
Шаг 1: Проанализируй текст. Объясни, почему ты считаешь это ошибкой. Объясни, почему это важно. Объясни, какие последствия могут быть. Объясни, как это связано с другими ошибками.
```

**Почему не работает:** Слишком много рассуждений, которые не нужны для решения задачи.

**Корректно:**

```
Шаг 1: Проанализируй текст на логические ошибки. Объясни, почему ты считаешь это ошибкой. Если нашёл ошибку, исправь её.
```

**Ошибка 2: Отсутствие чёткой последовательности**

**Некорректно:**

```
Проанализируй текст. Проверь факты. Улучши стиль. Выведи финальную версию.
```

**Почему не работает:** Нет явной связи между шагами. Нейросеть может не понять, что результат одного шага нужен для следующего.

**Корректно:**

```
Шаг 1: Проанализируй текст на логические ошибки. Объясни, почему ты считаешь это ошибкой. Если нашёл ошибку, исправь её.

Шаг 2: На основе исправлений из шага 1 проверь факты. Если факт неверен, исправь его и объясни, почему.
```

**Ошибка 3: Слишком много шагов**

**Некорректно:** 10 шагов в одном промпте.

**Почему не работает:** Нейросеть теряет фокус и начинает игнорировать шаги.

**Корректно:** 3–5 шагов в одном промпте.

**Ошибка 4: Отсутствие вывода**

**Некорректно:**

```
Шаг 1: Проанализируй текст.
Шаг 2: Проверь факты.
Шаг 3: Улучши стиль.
```

**Почему не работает:** Нет итогового результата. Нейросеть не понимает, что нужно вывести в конце.

**Корректно:**

```
Шаг 1: Проанализируй текст.
Шаг 2: Проверь факты.
Шаг 3: Улучши стиль.
Вывод: Итоговый текст с комментариями.
```

## Комбинирование ReAct с другими методами (роли, цепочки)

**Комбинирование 1: ReAct + Роли**

```
Ты — редактор научного журнала. Найди и исправь ошибки в тексте статьи о климате. Работай по шагам:

Шаг 1: Проанализируй текст на логические ошибки. Объясни, почему ты считаешь это ошибкой. Если нашёл ошибку, исправь её.

Шаг 2: Проверь факты. Если факт неверен, исправь его и объясни, почему.

Шаг 3: Улучши стиль. Объясни, какие изменения ты вносишь и почему.

Шаг 4: Выведи финальную версию с комментариями к каждому исправлению.

Вывод: Итоговый текст + краткое резюме рассуждений.
```

**Комбинирование 2: ReAct + Цепочка промптов**

```
Шаг 1: Проанализируй текст на логические ошибки. Объясни, почему ты считаешь это ошибкой. Если нашёл ошибку, исправь её.

Шаг 2: На основе исправлений из шага 1 проверь факты. Если факт неверен, исправь его и объясни, почему.

Шаг 3: На основе исправлений из шагов 1 и 2 улучши стиль. Объясни, какие изменения ты вносишь и почему.

Шаг 4: Выведи финальную версию с комментариями к каждому исправлению.

Вывод: Итоговый текст + краткое резюме рассуждений.
```

**Комбинирование 3: ReAct + Self-Check**

```
Шаг 1: Проанализируй текст на логические ошибки. Объясни, почему ты считаешь это ошибкой. Если нашёл ошибку, исправь её.

Шаг 2: Проверь факты. Если факт неверен, исправь его и объясни, почему.

Шаг 3: Улучши стиль. Объясни, какие изменения ты вносишь и почему.

Шаг 4: Проверь свой ответ по критериям: 1) полнота, 2) отсутствие сложных терминов, 3) мотивирующий тон.

Шаг 5: Если есть ошибки, исправь их и выведи финальный вариант.

Вывод: Итоговый текст + краткое резюме рассуждений.
```

## Практические рекомендации по формулировке ReAct-промптов

**Рекомендация 1: Начало: «Рассуждай пошагово, объясняя каждый шаг»**

**Некорректно:** «Найди и исправь ошибки.»

**Корректно:** «Найди и исправь ошибки. Рассуждай пошагово, объясняя каждый шаг.»

**Рекомендация 2: Шаг 1: рассуждение («Почему это важно?») + действие («Что сделать?»)**

**Некорректно:** «Проанализируй текст.»

**Корректно:** «Проанализируй текст на логические ошибки. Объясни, почему ты считаешь это ошибкой. Если нашёл ошибку, исправь её.»

**Рекомендация 3: Шаг 2: повторение цикла**

**Некорректно:** «Проверь факты.»

**Корректно:** «На основе исправлений из шага 1 проверь факты. Если факт неверен, исправь его и объясни, почему.»

**Рекомендация 4: Финал: итоговый результат + краткое резюме рассуждений**

**Некорректно:** «Выведи финальную версию.»

**Корректно:** «Выведи финальную версию с комментариями к каждому исправлению. Вывод: Итоговый текст + краткое резюме рассуждений.»

**Рекомендация 5: Ограничь количество шагов (3–5 оптимально)**

**Некорректно:** 10 шагов в одном промпте.

**Корректно:** 3–5 шагов в одном промпте.

**Рекомендация 6: Тестируйте ReAct на небольшом примере**

Прежде чем использовать ReAct на реальных данных, **протестируйте** его на небольшом примере.

## Заключение

ReAct — это мощный метод для сложных задач, требующих пошагового решения. Главное — чётко формулировать рассуждение и действие для каждого шага, повторять цикл до достижения цели и добавлять вывод с кратким резюме рассуждений. В следующей статье вы узнаете, как использовать метод Self-Consistency для выбора лучшего ответа из нескольких вариантов.
