# Чёткая формулировка задачи: как избежать двусмысленности

## Правила конкретности

**Конкретность** — это точность формулировки. Чем конкретнее задача, тем точнее результат. Модель не «понимает» намерение — она предсказывает токены на основе паттернов. Если задача расплывчатая, модель «выберет» наиболее вероятный паттерн, который может не совпадать с вашим намерением.

**Признаки расплывчатой задачи:**
- Общие слова: «напиши», «сделай», «объясни» без уточнений
- Отсутствие измеримых параметров: длина, формат, структура
- Субъективные оценки: «интересно», «хорошо», «подробно»
- Множественные действия в одной задаче: «напиши пост + сделай визуал + напиши caption»

**Признаки чёткой задачи:**
- Конкретное действие: «напиши продающий текст», «составь список», «разбей на этапы»
- Измеримые параметры: «150–200 слов», «3 тезиса», «таблица из 5 строк»
- Явная структура: «4 блока: Hook → Проблема → Решение → CTA»
- Одно действие: «напиши пост» (не «напиши пост + сделай визуал»)

## Как избежать двусмысленности

**Двусмысленность** — это когда одно и то же слово или фразу можно понять по-разному. Модель «выберет» наиболее вероятный вариант, который может не совпадать с вашим намерением.

**Примеры двусмысленности:**

| Расплывчатая формулировка | Двусмысленность | Чёткая формулировка |
|---------------------------|-----------------|---------------------|
| «Напиши про кофе» | Про что именно? (история, рецепт, продающий текст?) | «Напиши продающий текст для лендинга кофейни (150–200 слов)» |
| «Сделай интересным» | Что значит «интересным»? (юмор, факты, истории?) | «Добавь 2 примера из реальной практики» |
| «Объясни подробно» | Насколько подробно? (1 абзац? 3 страницы?) | «Объясни в 3 абзаца: определение → пример → применение» |
| «Напиши пост» | Сколько слов? Структура? Эмодзи? | «Напиши пост для Instagram (100–120 слов), Hook → Benefit → CTA» |

**Экспертный совет:** если формулировка вызывает вопросы «что значит?» или «насколько?» — она двусмысленная. Уточняйте.

## Примеры «расплывчатых» и «чётких» промптов

### Пример 1. Генерация идей

**Расплывчатый:**
```
"Придумай идеи для постов про кофе."
```

**Проблема:** сколько идей? Какая кофейня? Какая аудитория? Какой tone of voice?

**Чёткий:**
```
"Ты — SMM-менеджер кофейни 'Чёрный кот' (специалитет: авторские бленды, минимализм).
Целевая аудитория: IT-специалисты 25–35 лет.
Предложи 5 идей постов для Instagram на неделю.
Формат: нумерованный список, для каждой идеи — заголовок (3–5 слов) + 1 предложение.
Ограничения: без эмодзи, без хэштегов, без призыва 'подписывайся'."
```

**Результат:** 5 идей, связанных с брендом, в заданном формате, без лишних элементов.

---

### Пример 2. Объяснение термина

**Расплывчатый:**
```
"Объясни, что такое prompt engineering."
```

**Проблема:** для кого? Насколько подробно? С примерами или без?

**Чёткий:**
```
"Ты — технический писатель с опытом в NLP.
Объясни, что такое prompt engineering, для аудитории junior-разработчиков.
Используй 1 аналогию из реальной жизни.
Формат: 4–5 предложений, не больше 80 слов.
Ограничения: не используй термины 'токен', 'вектор', 'embedding'."
```

**Результат:** targeted объяснение с аналогией, заданной длины, без лишних терминов.

---

### Пример 3. Анализ ситуации

**Расплывчатый:**
```
"Проанализируй, почему продажи упали."
```

**Проблема:** какие данные? За какой период? Какие метрики? Какой формат ответа?

**Чёткий:**
```
"Ты — аналитик с 10-летним опытом в e-commerce.
Проанализируй, почему продажи упали на 15% за последний квартал.
Данные: CAC вырос на 40%, LTV упал на 10%, churn вырос на 5%.
Формат: таблица Markdown, 3 колонки: Гипотеза | Данные | Рекомендация.
Ограничения: ровно 5 гипотез, без 'воды', без общих фраз."
```

**Результат:** 5 гипотез в таблице, с данными и рекомендациями.

## Техника «5W1H»: подробный разбор

**5W1H** — это техника формулировки задачи через 6 вопросов:

- **Who** (Кто?) — для кого результат? (аудитория, роль, уровень)
- **What** (Что?) — что именно нужно сделать? (действие, тип контента)
- **When** (Когда?) — когда нужно? (срок, контекст)
- **Where** (Где?) — где будет использоваться результат? (платформа, канал, среда)
- **Why** (Зачем?) — зачем нужен результат? (цель, задача, проблема)
- **How** (Как?) — как должен выглядеть результат? (формат, структура, критерии)

**Пример применения 5W1H:**

| Вопрос | Ответ | Пример формулировки |
|--------|-------|---------------------|
| **Who** | CTO и Head of Engineering | «для аудитории CTO и Head of Engineering в компаниях 50–200 сотрудников» |
| **What** | Продающий текст | «Напиши продающий текст для лендинга» |
| **When** | Запуск продукта через 2 недели | «с акцентом на скорость внедрения (2 недели)» |
| **Where** | Лендинг продукта | «для лендинга продукта X» |
| **Why** | Привлечь инвесторов | «цель: привлечь внимание инвесторов» |
| **How** | 4 блока, 150–200 слов | «Формат: 4 блока: Hook → Проблема → Решение → CTA. Максимум 200 слов» |

**Полная формулировка задачи по 5W1H:**
```
"Напиши продающий текст для лендинга продукта X (Who: CTO и Head of Engineering в компаниях 50–200 сотрудников; What: продающий текст; When: запуск через 2 недели; Where: лендинг; Why: привлечь инвесторов; How: 4 блока, 150–200 слов)."
```

**Экспертный совет:** не обязательно отвечать на все 6 вопросов в каждом промпте. Достаточно 3–4 ключевых. Если задача простая (перевести текст), достаточно 2–3 вопросов. Если сложная (анализ, стратегия) — используйте все 6.

## Практическое задание

**Цель:** научиться превращать расплывчатые промпты в чёткие с использованием техники 5W1H.

**Задание:**
1. Возьмите 5 расплывчатых промптов (ваши собственные или из открытых источников).
2. Для каждого промпта:
   - Выявите двусмысленности и «слабые места»
   - Примените технику 5W1H (ответьте на 3–6 вопросов)
   - Перепишите промпт, сделав его конкретным
3. Протестируйте оригинал и исправленную версию в одной модели.
4. Сравните результаты по критериям:
   - Соответствие ожиданию
   - Конкретность
   - Отсутствие двусмысленности
   - Точность

**Пример:**

```
Оригинал: "Напиши пост про кофе для Instagram."

Расплывчатость:
- Что именно писать? (продающий текст? история? рецепт?)
- Сколько слов? Структура?
- Какая кофейня? Какая аудитория?
- Эмодзи? Хэштеги?

Применение 5W1H:
- Who: IT-специалисты 25–35 лет
- What: продающий пост
- When: не критично
- Where: Instagram
- Why: привлечь внимание к кофейне
- How: 100–120 слов, Hook → Benefit → CTA

Исправленный промпт:
"Ты — SMM-менеджер кофейни 'Чёрный кот' (специалитет: авторские бленды, минимализм).
Целевая аудитория: IT-специалисты 25–35 лет.
Напиши пост для Instagram (100–120 слов), акцент на 'кодинг до утра' и 'фокус'.
Ограничения: без хэштегов, без ссылок, без призыва 'подписывайся'.
Формат: Hook (1 предложение) → Benefit (2–3 предложения) → CTA (1 предложение)."
```

**Критерии проверки:**
- 5 промптов разобраны и переписаны
- Каждый переписанный промпт содержит минимум 3 компонента 5W1H
- Результаты оригинала и исправленной версии сравнены
- Переписанные промпты чёткие и конкретные

## Чек-лист: 6 правил чёткой формулировки

| Правило | Вопрос для проверки | 🟢 Обязательно | 🟡 Рекомендуется | 🔴 Опционально |
|---------|---------------------|----------------|------------------|----------------|
| **1. Конкретное действие** | Указано ли конкретное действие (напиши, составь, разбей)? | ✓ | | |
| **2. Измеримые параметры** | Указана ли длина, количество, структура? | ✓ | | |
| **3. Аудитория** | Для кого результат? (роль, уровень, контекст) | | ✓ | |
| **4. Цель** | Зачем нужен результат? (проблема, задача) | | ✓ | |
| **5. Одно действие** | Одно действие или несколько? (если несколько — разбить на цепочку) | ✓ | | |
| **6. Отсутствие двусмысленности** | Есть ли слова, которые можно понять по-разному? | ✓ | | |

**Экспертный совет:** начинайте с правил 1, 2, 5, 6 (конкретное действие, измеримые параметры, одно действие, отсутствие двусмысленности). Добавляйте правила 3 и 4 (аудитория, цель), если результат «общий» или «не в тему».

## Заключение

Чёткая формулировка задачи — это не «мелочь», а фундамент качественного промпта. Техника 5W1H помогает систематически уточнять задачу и избегать двусмысленности. Применяйте её, когда результат «не тот» или «слишком общий».

В следующей статье вы разберёте, как нейросеть «читает» промпт: токены, порядок, длина — и почему «первые» и «последние» токены важнее, чем середина.
